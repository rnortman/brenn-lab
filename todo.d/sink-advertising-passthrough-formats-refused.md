The sink client fails on a sound-server sink that advertises compressed passthrough formats (TrueHD, DTS-HD) beside PCM, with "invalid format encoding", so such a sink can be played on only after the sound server is configured to advertise PCM alone. Done when a play on a sink advertising those formats completes, held by a default test against the stand-in sound server. The comment sits where the sink client asks the server for a sink's description, in `brenn_lab/playback/pulse_client/src/main.rs`.
