A question for the owner, to be answered before any cross-machine control work starts here: does that work wait for the brenn bus to carry blobs, or start once the bus carries binary channels? The harness's plan is that control of devices on other machines runs over the brenn bus while bulk audio stays in files. What is undecided is how a capture recorded on one machine reaches the run directory on another. If binary channels are enough, the cross-machine work can start on the bus as it is, captures are copied between machines by ordinary file transfer (which needs ssh credentials on every machine involved), and fetching a capture is kept as one replaceable step so that a blob transfer over the bus can be added beside it later. If blobs are wanted, captures travel over the bus under the bus's own authentication, no machine needs another's ssh credentials, and the cross-machine work does not start until the bus ships blob transfer. Done when the owner has answered and the answer is recorded where the cross-machine work is planned. See `TODO(cross-machine-control-waits-on-bus-blob-transfer)`.
