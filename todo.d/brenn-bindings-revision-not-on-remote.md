Control of devices on other machines runs over the brenn bus through brenn's Python binding, which brenn-lab will build from brenn by commit, as it builds brenn-pod's programs. A pinned commit is fetched from brenn's public remote with the host's git, so the commit that holds the binding has to be there before brenn-lab can name it. The binding has been built and attached to a server only on linux x86_64; on linux aarch64, where the C toolchain has no pinned sysroot, building it has not been tried. Done when `MODULE.bazel` pins a brenn commit that is on brenn's remote, and the build of the binding from that commit is part of `make check` and passes on both linux CPUs brenn-lab supports, x86_64 and aarch64.
