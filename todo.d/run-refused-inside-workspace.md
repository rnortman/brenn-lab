The runner refuses a run directory that lies inside the workspace it was started from, which holds only when it is started with `bazel run`. That is one location fewer than "the harness writes data where it is told to", chosen so that recordings cannot land in this public tree. Every run directory also hides itself from git with a `.gitignore` of its own, created first, wherever it is written, so the refusal is a second guard and not the one that keeps a run out of a commit. The owner's question: keep the refusal, or drop it and rely on the run's own ignore file. Done when the owner has ruled: kept, and this entry and its comment are deleted; or dropped, and the refusal, its test and the sentences on it in the reference document for experiments are removed. The `TODO(run-refused-inside-workspace)` comment sits in the runner where a run directory inside the workspace is refused.
