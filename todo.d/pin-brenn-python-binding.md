Control of devices on other machines runs over the brenn bus through brenn's Python binding, `brenn_bus`, which speaks attach v6 and moves blobs. brenn-lab will build it from brenn by commit, as it builds brenn-pod's programs. The binding has been built and attached to a server only on linux x86_64; on linux aarch64, where the C toolchain has no pinned sysroot, building it has not been tried. Done when `MODULE.bazel` pins a brenn commit, and the build of the binding from that commit is part of `make check` and passes on both linux CPUs brenn-lab supports, x86_64 and aarch64.
