In brenn-lab. Control of devices on other machines runs over the brenn bus, and that work starts on the bus as it carries binary channels; it does not wait for the bus to carry blobs. Bulk audio does not ride the bus: a capture recorded on one machine stays in a file there, and the run directory on another machine holds the capture or a pointer to it. What this entry holds is how the capture gets there. When cross-machine control is built, bringing a capture from the machine that recorded it into the run directory is one replaceable step: a pointer left in the run directory, or a copy by ordinary file transfer, which needs credentials between the machines involved. It is kept to one step so that a transfer over the bus, under the bus's own authentication and with no machine holding another's credentials, can be added beside it once the bus ships blob transfer. Done when a run whose capture role is on another machine has its capture, or a pointer to it, in the run directory through that one step, and the run-directory reference names the step and what replaces it.
