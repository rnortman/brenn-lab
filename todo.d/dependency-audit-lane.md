A licence and advisory audit of the dependency graph (Python packages and the gate tools' crates), through Bazel, as its own target outside the default check. Done means the lane exists, runs clean, and a dependency with a non-permissive licence fails it. Deferred from the scaffold because the dependency set is small and the declared licence of every locked Python package and of every crate in the gate tools' lock files was read by hand at the first commit; all are permissive except `pathspec` 1.1.1 (a dependency of mypy), which declares MPL-2.0. That reading is not an audit: it covers no advisory and no licence text. The lane is owed before the first release, and each new third-party dependency before then is checked by hand the same way.
